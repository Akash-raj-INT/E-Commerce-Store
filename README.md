# E-Commerce Web Application

A responsive Angular e-commerce application built for product browsing, searching, routing, and cart management.

## Live Demo
[View deployed app](https://e-commerce-store-6b1o.onrender.com)

## Features
- Product listing and detail pages
- Search and filtering
- Add/remove cart functionality
- Client-side routing with Angular Router
- REST-style product loading from `assets/products.json`

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. Open the app at `http://localhost:4200`
